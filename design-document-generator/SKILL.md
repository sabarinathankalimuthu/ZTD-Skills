name: design-document-generator
description: Use whenever the user provides an FRD, functional requirements, BRD, user stories, process notes, or module requirements and wants a Design Document as a Word (.docx) file. Triggers include phrases like "write a design document", "generate technical design", "create solution design", "turn this FRD into a design document", or uploads of an FRD — especially for ServiceNow modules such as ITSM, HRSD, CSM, ITOM, FSM, or platform workflows. The skill should analyze the FRD and produce a structured design document covering solution overview, architecture, data model, integrations, workflows, configurations, roles, security, validations, assumptions, dependencies, and implementation considerations. It should also generate and embed relevant images or diagrams for process flows, workflow steps, system architecture, integration architecture, and data flow wherever the FRD provides enough information.
argument-hint: "[module or process name]"
